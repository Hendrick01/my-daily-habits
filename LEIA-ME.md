Este pacote **não contém projeto**. O projeto é o **seu** `my-daily-habits`.

## Como começar

1. Abra o seu repositório `my-daily-habits` no computador.
2. **Copie** os arquivos e pastas deste pacote para a **raiz** do seu repositório (a pasta onde está o `package.json`):

```text
ATIVIDADE.md   AI_TUTOR.md   DIARIO.md   RESPOSTAS.md   LEIA-ME.md
docs/          .github/
```

3. **Não substitua o seu `README.md`.** No fim, você o reescreve descrevendo o **seu** projeto.
4. Faça um primeiro commit: `chore: prepara a atividade final`.

## Por onde seguir

Leia, nesta ordem:

1. `ATIVIDADE.md` — o enunciado, os critérios de aceite e a pontuação. **Inteiro, sem pular.**
2. `docs/00-COMECE-AQUI.md` — o mapa de tudo
3. `docs/01-GUIA-DE-ETAPAS.md` — o que fazer em cada etapa e como testar
4. `docs/02-ONDE-PROCURAR.md` — a página certa da documentação para cada dúvida
5. `docs/04-PROTOCOLO-DE-DEPURACAO.md` — leia **antes** de pedir ajuda

## O que você preenche

| Arquivo | O que vai nele |
| --- | --- |
| `RESPOSTAS.md` | as 8 missões de documentação, com URL |
| `DIARIO.md` | mínimo 5 entradas com mensagens de erro reais |
| `README.md` | ao final, reescreva descrevendo o **seu** projeto |

## Antes de instalar qualquer coisa

O roteador usado no módulo exige **Node 22.22 ou superior**. Confira com `node -v`. Rode todos os comandos **dentro da pasta do projeto** (confirme com `pwd`).
